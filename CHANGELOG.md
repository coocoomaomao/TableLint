## [0.1.0] - 2026-09-25

### Added
- initial TableLint CLI
- CSV, XLSX, and LaTeX table readers
- recursive supported-file discovery
- empty / duplicate header checks
- empty-column checks
- placeholder-value checks
- exact duplicate-row diagnostics
- percentage range checks
- p-value range checks
- informational decimal-precision diagnostics
- LaTeX caption / label diagnostics
- LaTeX tabular row-width diagnostics
- strict mode and JSON output
- Python 3.10–3.12 CI
- header-declared Mean ± SD / SEM format checks
- Mean (SD / SEM) format checks
- negative SD / SEM spread detection
- single-column confidence-interval syntax checks
- confidence-interval bound-order checks
- paired CI lower / upper column ordering checks
- opt-in significance-star / exact p-value consistency checks
- configurable significance-star thresholds
- native GitHub Actions workflow annotations
- reusable composite GitHub Action
- wheel / sdist build validation
- PyPI Trusted Publishing workflow
