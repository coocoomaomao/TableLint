# TableLint v0.1.0

The first public alpha release of **TableLint — ESLint for academic tables**.

TableLint provides conservative, deterministic QA for CSV, XLSX, and LaTeX tables before submission.

## Highlights

- CSV / XLSX / LaTeX table input
- recursive directory scanning
- empty / duplicate headers
- entirely empty columns
- leftover TODO / TBD / FIXME placeholders
- exact duplicate-row diagnostics
- percentage range checks
- p-value range checks
- informational decimal-precision diagnostics
- Mean ± SD / SEM and Mean (SD / SEM) format checks
- negative SD / SEM spread detection
- confidence-interval syntax and bound-order checks
- paired CI lower / upper checks
- opt-in significance-star ↔ exact p-value consistency
- configurable significance thresholds
- strict mode
- machine-readable JSON output
- native GitHub Actions annotations
- reusable composite GitHub Action
- Python 3.10–3.12 support

## Quick start

~~~bash
pip install tablelint
tablelint check results.xlsx
~~~

Scan a folder:

~~~bash
tablelint check tables/
~~~

Machine-readable output:

~~~bash
tablelint check tables/ --format json
~~~

Enable an explicit significance-star convention:

~~~bash
tablelint check results.csv --star-thresholds 0.05,0.01,0.001
~~~

## GitHub Actions

~~~yaml
- uses: coocoomaomao/TableLint@v0.1.0
  with:
    path: tables/
    strict: "true"
~~~

## Status

v0.1.0 is an alpha release. TableLint checks data representation and formatting rules that can be automated conservatively; it does not judge scientific validity or statistical plausibility.
